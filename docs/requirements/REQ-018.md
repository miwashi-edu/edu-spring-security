# REQ-018: Login should reject malformed requests

> Missing fields and broken JSON are rejected; credentials are never accepted in a URL.

## Test case

| | |
|---|---|
| **Id** | REQ-018 |
| **Tag** | `@Tag("REQ-018")` |
| **Suggested test** | White-box · Unit, Black-box · Security |
| **Suite** | Security |
| **Runs in** | `dev`, `stage` |
| **Precondition** | Server is running with the test accounts (`user`, `admin`, `superadmin`, password `TEST_PASSWORD`) |
| **Action** | POST without password; POST broken JSON; GET with credentials as query parameters |

**Expected result**

1. `400` for missing field and broken JSON, without internals
2. GET is not a login (`401`, `404` or `405`)
