# REQ-012: Responses should include security headers

> Every response carries headers that protect browsers, and reveals no server versions.

## Test case

| | |
|---|---|
| **Id** | REQ-012 |
| **Tag** | `@Tag("REQ-012")` |
| **Suggested test** | Black-box · Security |
| **Suite** | Smoke |
| **Runs in** | `dev`, `stage` (HSTS: `stage`) |
| **Precondition** | Server is running (default `http://localhost:8080`, override with `TEST_BACKEND_URL`) |
| **Action** | GET `/actuator/health` |

**Expected result**

1. `X-Content-Type-Options: nosniff`
2. `X-Frame-Options: DENY` or `SAMEORIGIN`
3. No version number in `Server`, no `X-Powered-By`
4. Stage: `Strict-Transport-Security` with `max-age`
