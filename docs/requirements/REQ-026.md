# REQ-026: Refresh token should be kept in a protected cookie

> The refresh token lives only in a cookie that scripts cannot read, that is not sent cross-site, and only to the auth endpoints.

## Test case

| | |
|---|---|
| **Id** | REQ-026 |
| **Tag** | `@Tag("REQ-026")` |
| **Suggested test** | Black-box · Security |
| **Suite** | Security |
| **Runs in** | `dev`, `stage` (Secure: `stage`) |
| **Precondition** | Server is running with the test accounts (`user`, `admin`, `superadmin`, password `TEST_PASSWORD`) |
| **Action** | POST `/api/auth`, inspect `Set-Cookie: refreshToken` |

**Expected result**

1. `HttpOnly`
2. `SameSite=Strict`
3. `Path=/api/auth`
4. Not in the response body
5. Stage: `Secure`
