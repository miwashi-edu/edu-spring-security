# REQ-005: Actuator exposure should not reveal unused paths

> Only the health and info endpoints are open; sensitive endpoints such as `env` are not exposed.

## Test case (smoke)

| | |
|---|---|
| **Id** | REQ-005 |
| **Tag** | `@Tag("REQ-005")` |
| **Suggested test** | White-box · Configuration, Black-box · Security |
| **Runs in** | `dev`, `stage` — skipped in prod, see [REQ-007](REQ-007.md) |
| **Precondition** | Server is running (default `http://localhost:8080`, override with `TEST_BACKEND_URL`) |
| **Action** | GET each sensitive actuator endpoint (not logged in): `env`, `beans`, `configprops`, `mappings`, `loggers`, `metrics`, `threaddump`, `heapdump` |

**Expected result**

1. Status code is `404` for every endpoint, as if it did not exist

## Test

```java
@Test
void shouldNotRevealUnusedPaths() {
    given()
        .baseUri("http://localhost:8080")
    .when()
        .get("/actuator/env")
    .then()
        .statusCode(404);
}
```

The smoke test is a `@ParameterizedTest` over all endpoints listed above, not only `env`.

The smoke test extends `SmokeTest`, so the base URI comes from `TEST_BACKEND_URL` instead of being hard-coded.
