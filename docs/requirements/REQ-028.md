# REQ-028: Reused refresh tokens should revoke the session

> A refresh token works once. Reuse means it was stolen, so the whole session is revoked.

## Test case

| | |
|---|---|
| **Id** | REQ-028 |
| **Tag** | `@Tag("REQ-028")` |
| **Suggested test** | Black-box · Security, White-box · Unit |
| **Suite** | Security |
| **Runs in** | `dev`, `stage` |
| **Precondition** | Server is running with the test accounts (`user`, `admin`, `superadmin`, password `TEST_PASSWORD`) |
| **Action** | Refresh twice with the same token; then refresh with the newest token |

**Expected result**

1. Second use: `401`
2. Newest token after reuse: `401`
