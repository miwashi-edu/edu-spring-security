# REQ-016: Users should log in with email and password

> User, admin and superadmin log in with email and password and receive an access token in the JSON body and a refresh token cookie.

| **Action** | POST `/api/auth` `{"email", "password"}` for each test account |

3. `Set-Cookie: refreshToken=...`
