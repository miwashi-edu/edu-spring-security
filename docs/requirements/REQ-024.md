# REQ-024: Protected API should accept only valid bearer tokens

> Only an unmodified, server-signed access token in `Authorization: Bearer` is accepted.

## Test case

| | |
|---|---|
| **Id** | REQ-024 |
| **Tag** | `@Tag("REQ-024")` |
| **Suggested test** | Black-box · Security, White-box · Unit |
| **Suite** | Security |
| **Runs in** | `dev`, `stage` |
| **Precondition** | Server is running with the test accounts (`user`, `admin`, `superadmin`, password `TEST_PASSWORD`) |
| **Action** | GET `/api/me` without token, with garbage, tampered (`roles: [SUPERADMIN]`), `alg: none`, foreign key, without `Bearer`, in `?access_token=`, and with the refresh token |

**Expected result**

1. Always `401`
2. Missing token: `WWW-Authenticate: Bearer`
