# REQ-008: Server should default to the prod profile

> When the server is started without a profile, it runs as `prod`, the most restrictive configuration.

## Test case (unit)

| | |
|---|---|
| **Id** | REQ-008 |
| **Tag** | `@Tag("REQ-008")` |
| **Suggested test** | White-box · Configuration |
| **Precondition** | None — the application is started inside the test (random port) |
| **Action** | Start the application without `SPRING_PROFILES_ACTIVE` |

**Expected result**

1. No profile is active
2. The default profile is `prod`
