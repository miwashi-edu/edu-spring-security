# REQ-031: Logout should end the session

> `POST /api/auth/logout` (cookie + CSRF) revokes the refresh token on the server and clears the cookie.

## Test case

| | |
|---|---|
| **Id** | REQ-031 |
| **Tag** | `@Tag("REQ-031")` |
| **Suggested test** | Black-box · Integration, Black-box · Security |
| **Suite** | Security |
| **Runs in** | `dev`, `stage` |
| **Precondition** | Server is running with the test accounts (`user`, `admin`, `superadmin`, password `TEST_PASSWORD`) |
| **Action** | Log in, log out, refresh with the old token |

**Expected result**

1. Logout: `200` or `204`
2. `Set-Cookie: refreshToken` with `Max-Age=0` or empty value
3. Refresh afterwards: `401`
