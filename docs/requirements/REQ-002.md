# REQ-002: Health endpoint should respond with JSON

> The health endpoint returns its status as JSON.

## Test case (smoke)

| | |
|---|---|
| **Id** | REQ-002 |
| **Tag** | `@Tag("REQ-002")` |
| **Suggested test** | Black-box · Smoke |
| **Runs in** | `dev`, `stage` — skipped in prod, see [REQ-007](REQ-007.md) |
| **Precondition** | Server is running (default `http://localhost:8080`, override with `TEST_BACKEND_URL`) |
| **Action** | GET `/actuator/health` (not logged in) |

**Expected result**

1. Status code is `200`
2. `Content-Type` contains `json`

## Test

```java
@Test
void shouldRespondWithJSON() {
    given()
        .baseUri("http://localhost:8080")
    .when()
        .get("/actuator/health")
    .then()
        .statusCode(200)
        .contentType(containsString("json"));
}
```

The smoke test extends `SmokeTest`, so the base URI comes from `TEST_BACKEND_URL` instead of being hard-coded.
