# REQ-007: Smoke tests should not run in production

> The smoke suite must not run against production, except REQ-001 (health endpoint should report `UP`),
> since the health endpoint may be public even in production (later protected by an API key).

## Test case

| | |
|---|---|
| **Id** | REQ-007 |
| **Suggested test** | Test process (no test) |
| **Runs in** | Applies to the whole smoke suite |
| **Precondition** | The test run declares its target with the environment variable `TEST_PROFILE` (`dev`, `stage` or `prod`; default `dev`) |
| **Action** | Run the smoke suite with `TEST_PROFILE=prod` |

**Expected result**

1. REQ-001 is executed
2. REQ-002 – REQ-006 are skipped, with the reason `Skipped on profile prod (runs only on dev, stage; ...)`
3. With `TEST_PROFILE=dev` or `TEST_PROFILE=stage`, all smoke tests are executed

| Requirement | dev | stage | prod |
|---|:-:|:-:|:-:|
| [REQ-001](REQ-001.md) Health endpoint should report UP | ✓ | ✓ | ✓ |
| [REQ-002](REQ-002.md) Health endpoint should respond with JSON | ✓ | ✓ | – |
| [REQ-003](REQ-003.md) Health endpoint should respond within two seconds | ✓ | ✓ | – |
| [REQ-004](REQ-004.md) Info endpoint should report active profile | ✓ | ✓ | – |
| [REQ-005](REQ-005.md) Actuator exposure should not reveal unused paths | ✓ | ✓ | – |
| [REQ-006](REQ-006.md) Unknown path should return not found | ✓ | ✓ | – |

## Test

```shell
TEST_PROFILE=prod TEST_BACKEND_URL=https://prod.example.com ./gradlew :app:smokeTest
```

The profile is declared by the test run instead of being asked from the server, because
production may not expose `/actuator/info`, and REQ-004 must not be gated by its own result.

## Tested by

No automated test: verified by running the smoke suite with `TEST_PROFILE=prod`.
Enforced by `@RunOnProfiles({"dev", "stage"})` on every smoke test except `HealthEndpointTest.shouldReportUP`.
