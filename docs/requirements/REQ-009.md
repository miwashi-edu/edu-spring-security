# REQ-009: Server should run with the profile it is started with

> The server supports the profiles `dev`, `stage` and `prod`, and runs with the one it is started with.

| | |
|---|---|
| **Id** | REQ-009 |
| **Tag** | `@Tag("REQ-009")` |
| **Suggested test** | White-box · Configuration |
| **Precondition** | None — the application is started inside the test (random port) |
| **Action** | Start the application with profile `dev`, `stage` or `prod` |

**Expected result**

1. Exactly that profile is active
