# REQ-011: Error responses should not reveal internal details

> Error responses never contain stack traces, exception class names or framework internals — not even in dev.

## Test case

| | |
|---|---|
| **Id** | REQ-011 |
| **Tag** | `@Tag("REQ-011")` |
| **Suggested test** | Black-box · Security, White-box · Configuration |
| **Suite** | Smoke |
| **Runs in** | `dev`, `stage` |
| **Precondition** | Server is running (default `http://localhost:8080`, override with `TEST_BACKEND_URL`) |
| **Action** | GET an unknown path; POST malformed JSON to `/api/auth` |

**Expected result**

1. Body contains no `"trace"`
2. Body contains no `Exception`
3. Body contains no `at org.springframework`

Finding: in dev the server currently returns the full stack trace (`"trace": ...`) because devtools enables it. Set `server.error.include-stacktrace: never`.
