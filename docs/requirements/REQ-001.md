# REQ-001: Health endpoint should report UP

> The health endpoint responds with status `UP`.

## Test case (smoke)

| | |
|---|---|
| **Id** | REQ-001 |
| **Tag** | `@Tag("REQ-001")` |
| **Suggested test** | Black-box · Smoke |
| **Runs in** | `dev`, `stage`, `prod` — may be public in prod (later protected by API key), see [REQ-007](REQ-007.md) |
| **Precondition** | Server is running (default `http://localhost:8080`, override with `TEST_BACKEND_URL`) |
| **Action** | GET `/actuator/health` (not logged in) |

**Expected result**

1. Status code is `200`
2. Response body field `status` equals `UP`

## Test

```java
@Test
void shouldReportUP() {
    given()
        .baseUri("http://localhost:8080")
    .when()
        .get("/actuator/health")
    .then()
        .statusCode(200)
        .body("status", equalTo("UP"));
}
```

The smoke test extends `SmokeTest`, so the base URI comes from `TEST_BACKEND_URL` instead of being hard-coded.
