# REQ-006: Unknown path should return not found

> The server answers unknown paths with 404 instead of an error or a redirect.

## Test case (smoke)

| | |
|---|---|
| **Id** | REQ-006 |
| **Tag** | `@Tag("REQ-006")` |
| **Suggested test** | Black-box · Smoke |
| **Runs in** | `dev`, `stage` — skipped in prod, see [REQ-007](REQ-007.md) |
| **Precondition** | Server is running (default `http://localhost:8080`, override with `TEST_BACKEND_URL`) |
| **Action** | GET `/this-path-does-not-exist` (not logged in) |

**Expected result**

1. Status code is `404`

## Test

```java
@Test
void shouldReturnNotFound() {
    given()
        .baseUri("http://localhost:8080")
    .when()
        .get("/this-path-does-not-exist")
    .then()
        .statusCode(404);
}
```

The smoke test also disables redirect following (`.redirects().follow(false)`); RestAssured follows
redirects by default, so a redirect to a 404 page would otherwise pass.

The smoke test extends `SmokeTest`, so the base URI comes from `TEST_BACKEND_URL` instead of being hard-coded.
