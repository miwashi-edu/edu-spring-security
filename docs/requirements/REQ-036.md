# REQ-036: Certificate login should reject invalid assertions

> Only an unmodified, fresh, single-use assertion for this service, signed by the registered key of the named user, is accepted.

## Test case

| | |
|---|---|
| **Id** | REQ-036 |
| **Tag** | `@Tag("REQ-036")` |
| **Suggested test** | Black-box · Security, White-box · Unit |
| **Suite** | Security |
| **Runs in** | `dev`, `stage` |
| **Precondition** | Server is running with the test accounts (`user`, `admin`, `superadmin`, password `TEST_PASSWORD`) |
| **Action** | POST `/api/auth/certificate` with: unknown key, other user's email, `alg: none`, HS256 with the public key as secret, tampered, expired, lifetime > 5 min, wrong `aud`, no `jti`, replay |

**Expected result**

1. Always `401`
