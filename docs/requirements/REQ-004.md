# REQ-004: Info endpoint should report active profile

> The info endpoint is open and reports which profile the server runs in.

## Test case (smoke)

| | |
|---|---|
| **Id** | REQ-004 |
| **Tag** | `@Tag("REQ-004")` |
| **Suggested test** | Black-box · Smoke, White-box · Configuration |
| **Runs in** | `dev`, `stage` — skipped in prod, see [REQ-007](REQ-007.md) |
| **Precondition** | Server is running (default `http://localhost:8080`, override with `TEST_BACKEND_URL`) |
| **Action** | GET `/actuator/info` (not logged in) |

**Expected result**

1. Status code is `200`
2. Response body field `profile` equals `dev` or `stage`

## Test

```java
@Test
void shouldReportActiveProfile() {
    given()
        .baseUri("http://localhost:8080")
    .when()
        .get("/actuator/info")
    .then()
        .statusCode(200)
        .body("profile", anyOf(equalTo("dev"), equalTo("stage")));
}
```

The smoke test extends `SmokeTest`, so the base URI comes from `TEST_BACKEND_URL` instead of being hard-coded.
